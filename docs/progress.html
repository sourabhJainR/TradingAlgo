TradingAlgo implementation progress

Batch 12 — Learning and validation layer — COMPLETE

  • Historical prediction snapshots, outcome tracking, look-ahead protection, chronological walk-forward validation, bounded factor calibration and predictive-value metrics.

Batch 13 — Point-in-time fundamental and valuation factor enrichment — COMPLETE

  • Point-in-time fundamental quality/growth, profitability, balance resilience, valuation hook and regression coverage for future-dated facts.

Batch 14 — Realized outcomes + predictive-value testing — COMPLETE

  • Every advisory receives a reproducible prediction ID tied to its exact as-of timestamp, horizon, score, confidence and signal/evidence snapshot.
  • Historical price realization uses the first session strictly after prediction time for entry and a horizon-qualified exit session, avoiding use of an unavailable daily close.
  • Realized return, benchmark-relative excess return, maximum adverse excursion and maximum favorable excursion are persisted against the exact prediction ID.
  • Walk-forward calibration uses prior training windows only, with correlation shrinkage and minimum-sample gates; bootstrap and permutation tests provide initial no-skill comparisons.
  • Regression tests cover horizon realization, leakage rejection, deterministic IDs, baselines, statistical tests and walk-forward evaluation.

Batch 15 — Holistic validation hardening — IN PROGRESS

  • Done: hardened LearningStore so outcomes cannot be persisted for unknown predictions, mismatched tickers or outcomes that have not matured beyond the snapshot horizon.
  • Done: normalized orchestrator as-of timestamps to UTC before both factor evaluation and snapshot creation, eliminating naive/aware timestamp drift.
  • Done: corrected validation to report the latest walk-forward calibration weights rather than averaging weights from future folds into earlier OOS results.
  • Remaining: validate statistical inference assumptions, add stronger baselines and multi-horizon risk metrics, then add automated outcome backfill/reporting.
