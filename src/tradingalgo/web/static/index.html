TradingAlgo Research

Free/public-data research with read-only portfolio connectors. No order execution.

Horizon-specific discovery ranks candidates using trend, momentum, liquidity, evidence and regime factors.

Uses public historical data and deterministic rules. No look-ahead execution is used.

Portfolio analysis

Analyze manually entered weights, a read-only Zerodha holdings snapshot, or an Excel/CSV export from Zerodha, INDmoney, or another broker.

Zerodha

Uses ZERODHA_API_KEY and ZERODHA_ACCESS_TOKEN on the server. The connector only reads holdings.

Excel / INDmoney import

Accepted columns include Symbol/Security, Quantity, Average Price, Current Value, LTP and P&L. The importer is read-only and keeps the original position values.

The pulse is computed from the analyzed discovery sample, not the complete exchange universe.
